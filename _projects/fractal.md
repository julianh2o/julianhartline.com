Fractal was a branch-iterating fractal generator written as a Java applet. Starting from a central node, it drew a set of initial branches; from the end of each one, more branches grew according to the settings, repeating for each iteration.

Every parameter (iterations, branch angle, length falloff, rotation, offset, color, and display style) could be adjusted live, and any of them could be animated over a range using a simple `min~max;step` syntax. Visitors could save their favorite fractals for others to browse and export animations as GIFs.
